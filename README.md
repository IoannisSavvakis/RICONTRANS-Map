# RICONTRANS Map v0.1.0
A web map application that visualizes RICONTRANS project's data.

<br>

For the GUI, React with TypeScript and Leaflet maps are being used.
<br>
The app/src/Objects.json file was generated using [Galaktion](https://github.com/IoannisSavvakis/Galaktion).

<br>

Screenshots of the app running are available in the screenshots folder.
